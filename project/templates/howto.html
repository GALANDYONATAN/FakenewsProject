How the System Works?

Step 1: Enter Your Data:

On the Home button, click Visit our Website, and the site will open with two options:
1.Transcribe a TikTok video
2.Transcribe text in order to check its credibility.
Refer only to the attribute in the text row that you need to enter in order to check its credibility.
You can Contact us to get the dataset for free. Enter the text you wish to select from the training set.
For video transcription, you will need to provide a URL — please make sure it is a valid address.

Example:

https://vt.tiktok.com/ZSrG3AdKh/

Step 2: Processing:

This code is a Flask application (a small Python web server) that serves HTML pages and also handles requests for text credibility checking and video transcription.

Libraries Used:

Flask-

for creating the server and managing pages/requests.

yt_dlp-

used to download videos from YouTube or TikTok (a modern fork of youtube-dl).

ffmpeg-

converts the downloaded video into a WAV audio file so it can be processed.

whisper-

OpenAI’s model for transcribing audio files into text.

ssl-

adjusts SSL settings to allow connections even without a valid certificate.

os-

manages files (delete, check existence, join paths).

pandas (pd)-

loads a CSV file containing text samples and credibility data (used for fake news detection).
In addition, we used these libraries for machine learning, and a detailed code implementation is provided in the Jupyter Notebook. The notebook explains how we identified the most suitable classifier and evaluated its performance. Based on this process, we created a dataset containing all the results.

Text Check Process (/send):


The user sends a text snippet (via JSON). The code searches for this text inside the CSV file (tik_tok_predictions_full_backup.csv) in the "text_snippet" column. If a match is found,the system returns data: whether it is classified as fake news and the corresponding Reliability/Unreliability scores. If no match is found,the system returns an error. Here, there is no transcription — only a lookup and comparison against existing dataset values.

Video Transcription Process (/transcribe):


The system receives a video link (video_url) from the user. If old files video.mp4 or audio.wav exist,they are deleted to ensure a clean start.
Using yt_dlp-the video is downloaded and saved as video.mp4. Using ffmpeg-the audio track is extracted from the video and saved as audio.wav in the proper format (mono, 16kHz, PCM).
The audio file is sent to the Whisper model for transcription:
result = whisper_model.transcribe("audio.wav", language="en").
The model processes the audio and returns the corresponding text. The system responds with the transcription as JSON: { "transcription": "..." } ,This step combines three libraries working together: yt_dlp (download), ffmpeg (audio extraction), whisper (speech-to-text transcription).

Step 3: Results:


In the video transcription image, you can see that the text has been fully transcribed — everything spoken in the video is displayed.

In the text transcription image, you can view the final results: whether the text is reliable or unreliable (in other words, whether it represents a factual claim or just an opinion). The output also shows the percentage of credibility and the percentage of falsehood. This way, you can clearly see whether a given text, according to TikTok parameters, is considered credible or not.

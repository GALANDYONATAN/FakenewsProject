How the System Works?

Step 1: Enter Your Data:

On the Home button, click Visit our Website, and the site will open with one option:
Check Video Reliability
To Evaluate the reliability of a TikTok video, you will need to provide a URL — please make sure it is a valid address.

Example:

https://vt.tiktok.com/ZSrG3AdKh/

Step 2: Processing:

This code is a Flask application (a small Python web server) that serves HTML pages and also handles requests for text credibility checking and video transcription.

Libraries Used:

Flask-

for creating the server and managing pages/requests.

yt_dlp-

used to download videos from YouTube or TikTok (a modern fork of youtube-dl).

ffmpeg-

converts the downloaded video into a WAV audio file so it can be processed.

whisper-

OpenAI’s model for transcribing audio files into text.

ssl-

adjusts SSL settings to allow connections even without a valid certificate.

os-

manages files (delete, check existence, join paths).

pandas (pd)-

loads a CSV file containing text samples and credibility data (used for fake news detection).
In addition, we used these libraries for machine learning, and a detailed code implementation is provided in the Jupyter Notebook. The notebook explains how we identified the most suitable classifier and evaluated its performance. Based on this process, we created a dataset containing all the results.

Video Transcription & Verification Flow (/transcribe):


The client sends a JSON with a TikTok video link: {"url": "<video_url>"}.
The server removes any leftover files (video.mp4, audio.wav) to start clean.
Download: Using yt_dlp, the video is downloaded and saved as video.mp4.
Audio extraction: Using ffmpeg, the audio track is extracted to audio.wav (mono, 16kHz, PCM).
Transcription: A Whisper base model is loaded and called:
result = whisper.load_model("base").transcribe("audio.wav", language="en")
The transcribed text is taken from result["text"] and trimmed.
Dataset lookup: The full transcript is looked up in the CSV-backed DataFrame (df) by exact match on the text column:
df["text"].str.strip() == transcript.
Response:
  • If the transcript is empty → {"error": "No text received"} (HTTP 400).
  • If no matching row is found in the dataset → {"error": "Text not found in dataset"} (HTTP 404).
  • If a match is found → the endpoint returns the saved verification fields:
{ "Fake news check": "...", "Reliability": <float>, "Unreliability": <float> }

This flow combines three core libraries working together:

  • yt_dlp – video download
  • ffmpeg – audio extraction (WAV, mono, 16 kHz, PCM)
  • whisper – speech-to-text transcription

Additionally, pandas is used to search the dataset for an exact transcript match and return precomputed credibility results.

Step 3: Results:


The user enters a TikTok video link, clicks Transcribe, and the system processes the video to check its credibility. A loading message indicates progress until results are displayed."
In the text transcription image, you can view the final results: whether the video is reliable or unreliable (in other words, whether it represents a factual claim or just an opinion). The output also shows the percentage of credibility and the percentage of falsehood. This way, you can clearly see whether a given video, according to TikTok parameters, is considered credible or not.
